# Analysis inputs

Download the original processed files from the source projects with `python scripts/fetch_inputs.py` from the reproduction directory. The downloader checks the versioned file hashes in upstream_manifest.json. Original datasets and original third-party R scripts are not included in this repository.

The two prior_OLS CSV files are derived reference fixtures used by the saved sensitivity calculations. Input fingerprints are also recorded in ../audit/v4_input_hashes.json.
